# Aquila Portfolio Pro

Professional upgraded Next.js portfolio with animated hero, service section, improved project cards, and new Terracam + HTDev projects.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Customize links
In `app/page.tsx`, replace the `#` values in each project with your real GitHub, demo, or video links.

## Project images
Project backgrounds are stored in `public/projects/`. Replace any image there with your own screenshots if you want real project screenshots.
