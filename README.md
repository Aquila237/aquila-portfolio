# Aquila Portfolio

Next.js professional portfolio for Aquila Ananga Noah.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Customize
- Replace LinkedIn link in `app/page.tsx`
- Replace GitHub/demo links for each project
- Add screenshots in `public/projects`
- Add your resume as `public/resume.pdf`

## Deploy on Vercel
1. Push this folder to GitHub.
2. Go to Vercel and import the GitHub repository.
3. Deploy.
4. Add your custom domain in Vercel Project Settings > Domains.
